# Quiz

## Entry Points (Routes)

- Quiz landing: `GET /quiz` → `src/app/(site)/quiz/page.tsx` renders `QuizIntro`
- Quiz flow: `GET /quiz/start` → `src/app/(site)/quiz/start/page.tsx` renders `QuizRunner`

## Core Components

- `QuizIntro` (`src/components/QuizIntro.tsx`)
  - Checks if a quiz session exists in local storage and offers “Continue your quiz” if there are saved answers.
  - “Start the Quiz” clears any saved session before navigating.
- `QuizRunner` (`src/components/QuizRunner.tsx`)
  - Client-side multi-step flow that records answers, branches between steps, and produces interim + final results.
  - Uses a route-leave interceptor via `NavigationContext` to show a “Leave quiz” modal before the final step.

## State & Persistence

- Local state: React `useState` inside `QuizRunner` tracks step, interim results, final results, and UI toggles.
- Persistent state: `src/lib/quizStorage.ts`
  - Session key: `k9cupid_quiz_session`
  - Final results key: `k9cupid_quiz_final_results`
  - TTL: 24 hours (`TTL_MS`)
  - Session includes: `id`, `startedAt`, `updatedAt`, `status`, `answers[]`
- Session access helper: `useQuizSession` (`src/hooks/useQuizSession.ts`)
  - Loads an existing session on mount; otherwise creates a new one on demand.
  - Persists every answer update to local storage.

## Questions

- Question definitions and option IDs live in `src/lib/quizQuestions.ts`.
- `QuizRunner` reads answers by question IDs and decides which step to show next.

## Interim Results (Server Action)

- `getQuizInterimBreeds` (`src/app/actions.ts`) is a server action used by `QuizRunner`.
  - Input: current answers (`{ id, value }[]`)
  - Output: `{ breeds: Dog[] }`
  - Uses helper functions from `src/lib/quizSizeUtils.ts` to derive suitability for sizes and constraints.
  - Retrieves the base dataset via `getBreeds` from `src/lib/api.ts`.

## Final Results (Client-side Scoring)

- Final ranking is computed in `src/lib/quizScoring.ts` and used by `QuizRunner`.
- Result explanation text is generated by `src/lib/quizAnalysis.ts`.
- Final results are persisted via `saveQuizFinalResults` in `src/lib/quizStorage.ts`.

## Where Results Are Shown

- The Account page (`src/app/(site)/account/page.tsx`) reads quiz session + final results from local storage and renders:
  - “What We Know” summary from `quizAnalysis`
  - Final breeds list (when available)
